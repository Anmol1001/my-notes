**What are the three main navigation concepts in mobile apps that differ from web navigation?**
	Bottom tabs, modals, and stack navigator
**What is the purpose of a layout file in Expo Router?**
	A layout file (named `_layout.tsx`) tells how screens in a folder should be laid out, such as defining navigation type (stack, tab, modal) and adding headers
**What is the significance of the scheme in mobile app deep linking?**
	The scheme allows a mobile app to register and listen for specific URL intents, enabling apps to respond when a particular URL scheme is triggered
**What library helps handle safe areas in mobile app development?**
	react-native-safe-area-context, which identifies the safe area of the screen to use for content placement.
